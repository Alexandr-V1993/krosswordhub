# CrosswordHub — crosswordhub.ru

Сайт русских кроссвордов на Next.js (App Router) и React.

- **Кроссворд дня** — один на всех, строится от даты.
- **480 готовых сеток** — по 60 в каждой из 8 тем (№1–20 лёгкие, 21–40 средние, 41–60 сложные).
- **Случайные кроссворды** — каждый раз новая сетка из словаря на 450+ слов.
- **Аккаунты** — регистрация, вход, профиль, серия дней подряд, прогресс по темам.
- **Автосохранение** недорешённых сеток и кнопка «Следующий кроссворд» после победы.
- **Подсветка ошибок красным** сразу при вводе и **таймер** с паузой (время сохраняется и попадает в прогресс).
- **Свой адрес и свои мета-данные у каждой страницы** (492 страницы), sitemap, robots, манифест.

## Адреса страниц

| Адрес | Что это | Индексируется |
| --- | --- | --- |
| `/` | главная, кроссворд дня | да |
| `/catalog` | каталог тем | да |
| `/catalog/<тема>` | 60 сеток темы (`mix`, `nature`, `travel`, `culture`, `food`, `science`, `everyday`, `sport`) | да |
| `/catalog/<тема>/<1–60>` | конкретный кроссворд | да |
| `/about` | о проекте | да |
| `/privacy` | политика конфиденциальности и cookie | да |
| `/progress` | личный прогресс | нет (`noindex`) |
| `/sitemap.xml`, `/robots.txt`, `/manifest.webmanifest` | служебные | — |

Любой другой адрес показывает страницу 404 (ответ сервера тоже 404).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Проверка перед выкладкой:

```bash
npm run typecheck
npm run build
npm start          # продакшен-сервер на порту 3000
```

Адрес сайта по умолчанию — `https://crosswordhub.ru`. Для тестового стенда его можно переопределить переменной `NEXT_PUBLIC_SITE_URL` (см. `.env.example`): она попадает в canonical, Open Graph, sitemap и robots.

## Публикация на crosswordhub.ru

Нужен Node.js 18.18 или новее.

**Вариант 1. Vercel (проще всего).** Залей папку в GitHub, на vercel.com выбери «Add New → Project», импортируй репозиторий и нажми Deploy. Затем в Settings → Domains добавь `crosswordhub.ru` и `www.crosswordhub.ru` и создай у регистратора DNS-записи, которые покажет Vercel. Сертификат https выпускается автоматически.

**Вариант 2. Свой сервер (VPS).**

```bash
git clone <твой-репозиторий> && cd crosswordhub
npm install && npm run build
npm install -g pm2 && pm2 start "npm start" --name crosswordhub && pm2 save && pm2 startup
```

DNS: A-запись `crosswordhub.ru` и `www` на IP сервера. Пример nginx (`/etc/nginx/sites-available/crosswordhub`):

```nginx
server {
    server_name crosswordhub.ru www.crosswordhub.ru;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Затем `certbot --nginx -d crosswordhub.ru -d www.crosswordhub.ru`. **Сайт должен открываться только по https**: без него браузер не даёт безопасно хэшировать пароли, а вход в аккаунт не сработает. Редирект `www` → без `www` (или наоборот) настрой у регистратора или в nginx, чтобы у страниц был один основной адрес.

## После запуска

1. Открой `https://crosswordhub.ru/robots.txt` и `https://crosswordhub.ru/sitemap.xml`: оба должны открываться.
2. Добавь сайт в **Яндекс Вебмастер** и **Google Search Console**, подтверди права и отправь `https://crosswordhub.ru/sitemap.xml`.
3. Проверь превью ссылки (картинка `public/og.png`) в Telegram, ВКонтакте и т. д.

## Яндекс Метрика

Счётчик **113971010** подключён в `components/Metrika.tsx` (`app/layout.tsx`) и работает **только на боевом сайте** (`npm run build` + `npm start` или деплой), в режиме разработки не загружается. Номер можно заменить переменной `NEXT_PUBLIC_METRIKA_ID`.

- Переходы между страницами внутри сайта отправляются вручную (`hit`), потому что страница не перезагружается.
- Цели («JavaScript-событие»), которые отправляет сайт: `puzzle_solved` (кроссворд решён, с параметрами level, category, seconds, assisted), `register` (регистрация), `login` (вход). Чтобы они появились в отчётах, создай в Метрике цели с такими же идентификаторами: Настройки → Цели → Добавить цель → JavaScript-событие.
- Поля формы входа помечены `ym-disable-keys`, поэтому Вебвизор не записывает набранные email и пароль.
- Метрика (с Вебвизором) включена на всех страницах, включая `/privacy`, без отдельного согласия.

## Реклама (РСЯ)

Рекламу Яндекса подключают `components/Ads.tsx` (загрузчик `context.js` + блоки) и `lib/ads.ts` (номера блоков). Работает только на боевом сайте. Четыре готовых блока (`floorAd` и `fullscreen`, для компьютера и телефона) Яндекс показывает сам: плавающий снизу и полноэкранный. Над сеткой кроссворда место готово (`GridAd`), но включится после того, как в `GRID_AD_BLOCK_ID` в `lib/ads.ts` вписан номер блока обычного формата.

## Политика конфиденциальности

Страница `/privacy` (`components/PrivacyPolicy.tsx`) есть в подвале каждой страницы и в `sitemap.xml`. **Перед запуском открой `lib/legal.ts` и впиши владельца сайта (ФИО или ИП) и e-mail для обращений**, пока там «УКАЖИТЕ…», эти места на странице подсвечены жёлтым. Когда добавишь рекламные блоки (РСЯ и т. п.), обнови текст политики: рекламные сети ставят свои cookie, и дату редакции в `lib/legal.ts` тоже.

### Добавить слова
В `lib/puzzles.ts` в блоке `RAW` слова записаны построчно: `ОТВЕТ|подсказка`. Добавляй новые строки в нужную тему. Если поменять набор слов, нумерованные кроссворды изменятся (у них адреса остаются, но сетки станут другими), поэтому добавляй слова до запуска.

### Сколько сеток в теме
Константа `PER_THEME` в `lib/puzzles.ts` (сейчас 60). Адреса, sitemap и мета-данные подстроятся сами.

## Важно про аккаунты

Аккаунты и прогресс хранятся **в браузере пользователя** (localStorage), на сервер ничего не отправляется. Пароль хранится как соль и хэш PBKDF2. Это значит:

- прогресс не переносится между устройствами и браузерами;
- если очистить данные сайта, прогресс пропадёт;
- восстановить пароль нельзя.

Если нужны настоящие аккаунты с синхронизацией, потребуется серверная часть: база данных (например PostgreSQL), API-маршруты Next.js и сессии в httpOnly-cookie. Замени функции в `lib/auth.ts`, интерфейс менять не придётся.

## Шрифты

Шрифты (Manrope, DM Sans) подключаются с Google Fonts через `<link>` в `app/layout.tsx`. Если нужно без внешних запросов, скачай их и подключи через `next/font/local`.
